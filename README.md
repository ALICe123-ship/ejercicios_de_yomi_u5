## Descripción

Este programa fue desarrollado en Python y permite administrar una playlist para un festival de música utilizando arreglos (listas).

El usuario puede:

- Agregar canciones.
- Registrar nombre, artista, duración y popularidad.
- Visualizar reportes de la playlist.
- Buscar canciones por artista.
- Buscar canciones por rango de popularidad.
- Generar una playlist recomendada con canciones cuya popularidad sea superior al promedio.
